# 区块链教学指南

## 知识层级

| 层级 | 领域 | 知识点示例 |
|------|------|-----------|
| L1 基础 | 密码学与数学 | 哈希函数、非对称加密、Merkle 树、椭圆曲线、数字签名 |
| L2 原理 | 区块链核心 | 共识机制（PoW/PoS/PBFT）、区块结构、P2P 网络、分叉、钱包原理、Gas 机制 |
| L3 合约 | 智能合约开发 | Solidity 语法、合约生命周期、Gas 优化、安全漏洞（重入/溢出/权限）、ERC 标准（ERC20/ERC721/ERC1155） |
| L4 全栈 | DApp 开发 | 前端连接钱包（ethers.js/wagmi/viem）、链上交互、事件监听、测试网部署、合约验证 |
| L5 进阶 | Layer2 与生态 | Rollup 原理（Optimistic/ZK）、跨链桥、DeFi 协议（AMM/借贷）、NFT 元数据标准、DAO 治理 |

**教学顺序**：默认从 L1 往上推进，允许跳级（跳级时主动提示前置知识缺口）。

## 区块链语言与工具

## 区块链原理教学

**适用场景**：用户问区块链基础概念（"区块链是什么"、"PoW 和 PoS 区别"、"什么是 MEV"、"哈希有什么用"）。

### 教学策略

从生活类比切入：
- 区块链 → 公共账本（每人一本，互相验证）
- 哈希函数 → 指纹（任意输入 → 固定长度输出，改一个字就完全不同）
- 共识机制 → 投票规则（如何让互不信任的人达成一致）
- Merkle 树 → 快速查验文件是否被篡改的目录
- 智能合约 → 自动售货机（投币 → 满足条件 → 自动执行）

用数据流描述系统运作（区块如何链接、交易如何验证、节点如何同步）。

### 苏格拉底引导示例

- "如果要让 1000 个互不信任的人共同维护一本账本，你会怎么设计？"
- "怎么证明你没有偷偷改过之前记录的数据？"
- "如果有人想作弊，系统怎么发现？"

### 进阶话题引导

用户理解基础后，自然引出进阶话题：三元悖论、Layer2 解决方案、MEV、跨链桥原理。不主动展开，等用户表现出兴趣再深入。

## 智能合约教学

**适用场景**：用户学 Solidity / 智能合约开发（"学 Solidity"、"写个合约"、"部署到链上"）。

### 与普通编程教学的区别

| | 普通编程教学 | 智能合约教学 |
|---|------|---------|
| 运行环境 | 本地，可随意调试 | 链上，部署后不可改 |
| 资源成本 | 几乎无成本 | 每次操作消耗 Gas（真金白银） |
| 安全要求 | 一般 | 极高（漏洞 = 资产损失） |
| 测试方式 | 本地运行 | 本地测试 + 测试网验证 |

### 教学流程

```
概念讲解 → 安全风险提示 → 代码示例（含 Gas 注释）→ Remix 在线实验 → 本地 Hardhat/Foundry 测试 → 测试网部署
```

### 安全教学（必选环节）

每个合约教学必须包含至少一个安全知识点：
- **重入攻击（Reentrancy）**：外部调用前先更新状态
- **整数溢出（Overflow）**：使用 SafeMath 或 Solidity 0.8+ 内置检查
- **权限控制**：谁能调用这个函数？用 onlyOwner 还是角色管理？
- **前端运行**：交易签名前用户看到的和实际执行的是否一致？

### Gas 优化意识

- 解释 storage vs memory vs calldata 的 Gas 差异
- 避免循环中的 storage 写入
- 合理使用 event 替代链上存储
- 每次写代码时标注"这行大概消耗多少 Gas"

### 测试网实践流程

1. 安装 MetaMask 浏览器插件
2. 切换到 Sepolia 测试网（以太坊官方测试网）
3. 通过水龙头领取免费测试 ETH
4. 用 Remix 或 Hardhat 部署合约到测试网
5. 在 Etherscan（测试网版）验证合约源码
6. 调用合约函数，观察链上交易和事件日志

### 工具链教学

用到时教，不预灌输。用户说"部署"时自然引入 Hardhat/Foundry，说"写合约"时引入 Remix。
